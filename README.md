# 敦煌星图 · 3D 天球交互式星空

以敦煌古星图为题材的交互式 3D 星空应用：单页 WebGL 天球 + 地平线观星台 + 观星社区 + 星辰图鉴 + 星签占卜，配 FastAPI 后端实现多人共享社区与智能体问答。

> 个人作品集项目 · 纯前端可离线运行，后端可选启用

## 在线看点

- **46 个可交互天体**：二十八宿 + 北斗 + 北极星 + 三垣（紫微/太微/天市）+ 13 颗著名亮星（织女一、天狼、参宿四……），点击即推进相机、弹出信息卡
- **30 条星宿故事库**：白话解说 + 古籍引文（《史记·天官书》、古诗十九首、苏轼、杜甫等）
- **最佳观星地推荐**：月光干扰 45% + 光污染 35% + 历史晴率 20% 加权评分，内置 24 地暗夜库，满月周自动降权
- **观星社区（双模式）**：检测到后端自动进入多人共享模式（注册/登录/发帖附星象快照/点赞/评论）；无后端回落 localStorage 本地模式
- **星辰图鉴**：四象分组 30 条目，含数据签 / 白话 / 古籍 / 传说 / 中西星官对照，观测点亮收集玩法
- **确定性星签**：日期 + 时辰 + 问事 → 二十八宿签，同参数两次必同签（可复现），28 条签文
- **智能体「小星童」**：右下角常驻 SVG 形象（3 款皮肤可换），指令分流 / 内置知识库 / 大模型三层应答，实时镜像主面板消息

## 技术栈

| 层 | 选型 |
|---|---|
| 渲染 | 原生 JavaScript + Three.js r147（WebGL，本地优先、CDN 兜底） |
| 天文计算 | Stellarium Web Engine（WASM），赤经赤纬 → 地平坐标实时换算 |
| 后端 | Python FastAPI + uvicorn，SSE 流式应答 |
| 存储 | SQLite（社区五表：users / sessions / posts / likes / comments） |
| 工程 | 单 HTML 主体 + hash 路由（`#c=star/horizon/community/atlas/fortune`） |

## 安全设计（社区后端）

- 密码 **PBKDF2-HMAC-SHA256，12 万轮迭代 + 每用户独立盐**，不存明文
- 会话 token 由 `secrets` 模块生成，独立 sessions 表持久化，服务重启不掉线
- 全部 SQL 参数化查询；外键约束 `ON DELETE CASCADE`
- 登录态与点赞幂等性经端到端验收（API 13 项 + 浏览器 8 项）

## 快速开始

**方式一 · 纯前端（免后端）**

双击 `启动(可定位).bat`，自动起一个本地静态服务并打开浏览器（经本地服务打开才能使用真实地理定位）；关闭黑色窗口即停止服务。

**方式二 · 带社区后端**

```bash
pip install fastapi uvicorn
python app.py
# 浏览器访问 http://127.0.0.1:8000/敦煌星图3D天球.html
```

页面探测到 8000 端口后端后，社区自动切换为多人共享模式。

## 工程细节

- **性能**：切到社区 / 图鉴 / 占卜页时主渲染循环自动暂停，返回恢复
- **响应式**：1600 / 1366 / 1024 / 390 四档宽度实测零重叠、零报错；尊重 `prefers-reduced-motion`
- **回归保障**：全流程 `window.__errs` 零报错校验；星宿宿序、占卜抽取等关键行为有确定性用例复测
- **观测点**：默认取用户所在地（V3.0），支持多格式经纬度输入与智能体指令跳转（「带我去 30.57,104.07」）

```
└── 功能对照表.md             # 63 项功能逐条审计记录
```
